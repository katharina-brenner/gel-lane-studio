# Lane Studio

Lane editor for gel and blot images.

## Features

- Local image upload
- 1–30 lanes
- Move, resize, distribute
- Label, font, size, weight, italics, color, angle, position
- PNG export

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

Image processing stays in the browser.
